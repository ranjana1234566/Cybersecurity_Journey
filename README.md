🔐 VAPT Report – Cybersecurity Journey

📌 Overview

This repository contains my **Vulnerability Assessment and Penetration Testing (VAPT) Report**, created as part of my cybersecurity learning journey.

The report documents the process of identifying, analyzing, and understanding security vulnerabilities in a controlled lab environment.

🎯 Objectives

* To understand the fundamentals of VAPT
* To perform reconnaissance and vulnerability analysis
* To identify security weaknesses in a target system
* To document findings in a professional report format

🛠️ Tools & Technologies Used

* Kali Linux 2025.4
* Nmap 7.98
* OWASP ZAP 2.17.0
* Burp suite community addition
* Firefox developer tools
* CVSS v3.1 Calculator (first.org)

🔍 Key Activities Performed

1. **Reconnaissance**

   * Information gathering using OSINT tools
   * Identifying target system details

2. **Scanning**

   * Port scanning using Nmap
   * Service and version detection

3. **Vulnerability Analysis**

   * Identifying open ports and weak services
   * Analyzing potential entry points

4. **Exploitation (Basic)**

   * Understanding exploitation techniques using Metasploit
   * Demonstrating controlled attacks in lab environment

5. **Reporting**

   * Documenting vulnerabilities
   * Providing possible mitigation strategies


⚠️ Disclaimer

This project was conducted in a **controlled and ethical environment** strictly for educational purposes.
No real systems were harmed or targeted without authorization.

* Gained hands-on experience in VAPT process
* Improved understanding of network security
* Learned how to document security findings professionally
